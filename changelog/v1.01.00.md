# Release Notes - v1.1.0

**Release Date:** November 18, 2025  
**Type:** Minor Release - Code Quality & Feature Enhancement

---

## Overview

Version 1.1.0 emphasizes code quality and developer experience. The addition of Prettier ensures consistent code formatting across the codebase, while comprehensive project rules establish clear development standards. The lookback hours feature provides more flexibility in monitoring configurations, allowing teams to customize their error detection windows.

---

## Added

### Code Formatting
- **Prettier Configuration** (`.prettierrc`)
  - 100 character print width for better readability
  - 2-space indentation for JavaScript/JSON
  - Single quotes preference
  - Trailing commas for ES5 compatibility
  - Special overrides for Apex files (4-space tabs)
  - Consistent formatting rules across the project

- **Prettier Ignore** (`.prettierignore`)
  - Excludes Salesforce metadata files (`.cls-meta.xml`, `.trigger-meta.xml`)
  - Excludes lock files (`pnpm-lock.yaml`, `package-lock.json`)
  - Excludes build artifacts and `node_modules`
  - Excludes specific configuration files
  - Prevents formatting of generated files

### Development Standards
- **Apex Development Rules** (`.cursor/rules/project-rules.mdc`)
  - DRY (Don't Repeat Yourself) principles
  - SOLID design patterns
  - Separation of Concerns guidelines
  - Code quality standards
  - Error handling best practices
  - Testing standards and requirements
  - Security guidelines (XSS prevention, input validation)
  - Governor limits documentation
  - Naming conventions
  - Bulkification requirements
  - Anti-patterns to avoid

### Features
- **Lookback Hours Support**
  - Configurable lookback periods for batch processing
  - Enhanced flexibility in monitoring windows
  - Allows custom time ranges for error detection
  - Better control over data volume and processing

### Documentation
- **Visual Documentation**
  - Added `AgentErrorMonitor-Overview.png` for better project visualization
  - Architectural diagram showing component relationships
  - Improved onboarding experience

  - Duplicate execution scenarios

**Benefit**: Cleaner test suite focused on meaningful behavior validation
